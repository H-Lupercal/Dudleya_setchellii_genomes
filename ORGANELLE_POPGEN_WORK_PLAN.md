## Objective

Use the annotated organelle references in this repo to analyze cpDNA and mtDNA
variation across the Dudleya sequencing samples.

Interpretation notes that still matter:

- There is no standalone rendered Neighbor Joining quick-check tree. IQ-TREE
  writes internal BIONJ starting trees, but the final tree deliverable is ML.
- Fst is a custom haploid Nei-style estimate averaged over informative SNPs.
- Population-level Fst/statistics use only samples with resolved population
  codes; unresolved DU-only samples remain in alignments/PCA/trees.
- mtDNA population genetics uses the 44,930 bp high-confidence unique track
  and 146 filtered SNPs, not the full repeat-rich mitochondrial contig.
- ADMIXTURE is used as organelle haplotype clustering, not nuclear admixture;
  haploid calls are pseudo-diploid homozygotes for tool compatibility.

Deliverables:

- cpDNA all-sample alignment.
- mtDNA all-sample alignment.
- cpDNA and mtDNA PCA plots.
- cpDNA and mtDNA phylogenetic trees, preferably maximum likelihood; Neighbor
  Joining is acceptable as a quick check.
- Structure/admixture-style plots with K selected empirically.
- Pairwise Fst and basic population summaries.
- Sample-level QC report.

## Reference Prep

cpDNA:

1. Use `dudleya_organelle_reference_verification/references/chloroplast.normalized.fa`.
2. Confirm the contig is named `chloroplast`.
3. Lift over or regenerate GFF3 coordinates if feature coordinates are needed
   against the normalized reference.
4. Create masks for the inverted repeat, repetitive/ambiguous regions, and
   low-confidence annotation intervals.
5. Index with `bwa index`, `samtools faidx`, and variant-caller indexes.

mtDNA:

1. Use `dudleya_organelle_reference_verification/references/mitochondria.fa`.
2. Confirm the contig is named `mitochondria`.
3. Create repeat and low-confidence-region masks from the reference-verification
   checks.
4. Keep a whole-mtDNA analysis for the first pass.
5. Add a conserved-gene-only mtDNA analysis if whole-contig results are noisy.
6. Index with `bwa index`, `samtools faidx`, and variant-caller indexes.

Useful pieces to reuse:

- `bwa mem` mapping.
- `samtools` sort, index, flagstat, idxstats, and depth summaries.
- Aggregate QC reporting.
- PCA plotting scaffolding.
- IQ-TREE plotting scaffolding.
- Snakemake config and WAVE/SLURM patterns.

Pieces to change:

- Use organelle references, not the nuclear reference alone.
- Remove nuclear chromosome scatter-gather.
- Treat cpDNA and mtDNA as haploid for primary variant calls.
- Use organelle-specific depth, breadth, missingness, and repeat masks.
- Keep cpDNA and mtDNA outputs separate.
- Interpret structure/admixture plots as haplotype clustering, not nuclear
  admixture.

Consider competitive mapping to a combined nuclear + cpDNA + mtDNA reference if
the nuclear reference is available. This should reduce false organelle calls from
nuclear organelle insertions and cross-organelle shared sequence.

## Variant Calling and Alignment

Primary path:

1. Map reads to cpDNA and mtDNA references.
2. Filter alignments by mapping quality and base quality.
3. Call haploid variant-only sites, for example with `bcftools mpileup` plus
   `bcftools call --ploidy 1 -m -v`.
4. Filter SNPs and indels separately.
5. Mask low-depth, repetitive, low-confidence, and high-missingness sites.
6. Build one consensus FASTA per sample.
7. Generate cpDNA and mtDNA all-sample alignments.
8. Generate SNP-only matrices for PCA, Fst, and clustering.

Optional low-coverage path:

- Adapt Evan's ANGSD/PCAngsd path if hard calls are unreliable.
- Confirm haploid/organelle assumptions before using ANGSD outputs downstream.

## Analyses

PCA:

- Run separately for cpDNA and mtDNA.
- Color points by population.
- Label outliers.
- Report SNP count and percent variance explained.

Trees:

- Run IQ-TREE on full callable-site consensus alignments where possible.
- Use `GTR+ASC` if using SNP-only alignments.
- Include a Neighbor Joining tree as a quick topology check.
- Root with an outgroup if one is included; otherwise report unrooted or
  midpoint-rooted trees.

Structure/admixture-style clustering:

- Run cpDNA and mtDNA separately.
- Test K across a fixed range, such as 1 to 8 or up to the number of sampled
  populations.
- Use cross-validation, likelihood, delta K, and replicate stability to select K.
- If a diploid-only tool is used, encode haploid calls consistently and document
  the encoding.

Fst and population summaries:

- Pairwise population Fst.
- Per-population sample counts.
- Callable bases per population.
- SNP count per comparison.
- Haplotype counts.
- Haplotype diversity.
- Nucleotide diversity.
- Private variants.
